# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The LifeLink team takes the security of patient health information, donor contact numbers, and authentication credentials seriously.

If you believe you have discovered a security vulnerability in LifeLink:

1. **Do not disclose the vulnerability publicly** via GitHub Issues or public social media.
2. Please send a direct email with a detailed description, reproduction steps, and potential impact to:
   - 📧 **adilraxiq64@gmail.com**
3. You will receive an acknowledgment within 48 hours.
4. We will investigate the report and release a patch as quickly as possible.

Thank you for helping keep LifeLink and its community safe!
